# برنامه محاسبه سهامداری

برنامه‌ای ویندوزی (Python + Tkinter) برای مدیریت فهرست سهامداران شرکت: تعداد سهام، سهام وثیقه، سهام اصلی (آزاد)، سریال شروع و پایان سهم، درصد مالکیت و ارزش اسمی، همراه با چاپ گزارش.

## امکانات
- فقط سه ورودی لازم است: **نام سهامدار، تعداد سهام، تعداد سهام وثیقه**
- بقیه خودکار محاسبه می‌شود: سهام آزاد، درصد، ابتدا/انتهای سریال سهام، ابتدا/انتهای/تعداد وثیقه و آزاد، و ردیف جمع
- سریال‌ها به ترتیب ردیف‌ها و از «سریال شروع» (پیش‌فرض ۱) پشت سر هم تخصیص می‌یابند؛ ترتیب با ▲ ▼ قابل تغییر است
- دو حالت جایگاه وثیقه در بازهٔ هر نفر: **ابتدای بازه** یا **انتهای بازه**؛ گزینهٔ «هر دو» در چاپ دو جدول می‌دهد
- کنترل خطا: وثیقه بیشتر از کل سهام
- چاپ گزارش A4 افقی و راست‌چین، **خروجی Excel (.xlsx)** با فرمت و شیت راست‌چین (در حالت «هر دو» دو شیت)، خروجی CSV، ذخیره خودکار، پذیرش ارقام فارسی

## پیش‌نیازها
- ویندوز ۱۰ یا ۱۱
- کتابخانه openpyxl برای خروجی Excel: `pip install -r requirements.txt`
- Python 3.9 یا بالاتر (از python.org؛ گزینه Add to PATH را بزنید). Tkinter همراه نصب استاندارد Python است و بسته اضافه‌ای لازم نیست.

## اجرا
```
pip install -r requirements.txt
python shareholders.py
```
یا فایل `run.bat` را دوبار کلیک کنید.

## ساخت فایل exe
```
build.bat
```
خروجی در `dist\Shareholders.exe` ساخته می‌شود و روی ویندوزِ بدون Python هم اجرا می‌شود.

### انتشار خودکار نسخه (Release)
workflow در `.github/workflows/build.yml` فایل exe را روی ویندوز می‌سازد، تگ را ایجاد می‌کند و `Shareholders.exe` را به Release پیوست می‌کند. دو راه:

1. **با تگ:**
   ```
   git tag v1.2.0
   git push origin v1.2.0
   ```
2. **دستی از GitHub:** تب Actions ← build-release ← Run workflow ← نسخه (مثلاً `v1.2.0`). تگ و Release توسط خود workflow ساخته می‌شود.

نکته: در Settings ← Actions ← General، گزینه Workflow permissions باید روی Read and write باشد (یا سازمان اجازهٔ نوشتن به workflow بدهد).

## نحوه استفاده
1. نام شرکت، سریال شروع و جایگاه وثیقه را بالای صفحه تنظیم و «اعمال» را بزنید.
2. نام، تعداد سهام و تعداد وثیقه را وارد و «ذخیره» را بزنید.
3. برای ویرایش، ردیف را در جدول انتخاب کنید، فرم را تغییر دهید و «ذخیره» بزنید.
4. «چاپ» گزارش را در مرورگر پیش‌فرض باز می‌کند و پنجره چاپ ویندوز ظاهر می‌شود؛ برای PDF از Save as PDF استفاده کنید.
5. «خروجی Excel» فایل xlsx با اعداد واقعی و قالب هزارگان می‌سازد.
6. «خروجی CSV» فایل CSV با کدگذاری UTF-8 می‌سازد.

## محل ذخیره داده‌ها

```json

  "company": "نام شرکت", "start0": 1, "mode": "start",
  "people": [{"name": "سپهرگاوه", "total": 2548611, "pledged": 10}]
}
```


## تعاریف و فرض‌ها
- سهام آزاد = کل سهام − سهام وثیقه
- درصد = سهام فرد ÷ مجموع سهام همه سهامداران
- حالت «ابتدا»: وثیقه ۱ تا ۱۰ و آزاد از ۱۱ تا انتها؛ حالت «انتها»: آزاد از ابتدا و وثیقه ۱۰ سهم پایانی بازه
