# برنامه محاسبه سهامداری

برنامه‌ای ویندوزی (Python + Tkinter) برای مدیریت فهرست سهامداران شرکت: تعداد سهام، سهام وثیقه، سهام اصلی (آزاد)، سریال شروع و پایان سهم، درصد مالکیت و ارزش اسمی، همراه با چاپ گزارش.

## امکانات
- ثبت، ویرایش و حذف سهامدار
- فیلدها: نام، کد ملی، تعداد کل سهام، سهام وثیقه، شروع سهم، پایان سهم، توضیحات
- محاسبه خودکار: سهام اصلی (آزاد) = کل − وثیقه، درصد مالکیت، ارزش اسمی هر نفر، سرمایه شرکت
- کنترل خطا: وثیقه بیشتر از کل سهام، پایان کوچک‌تر از شروع، همپوشانی بازه سریال بین سهامداران، مغایرت تعداد بازه با کل سهام (هشدار)
- چاپ گزارش A4 افقی و راست‌چین با ردیف جمع
- خروجی CSV برای Excel
- ذخیره خودکار اطلاعات
- پذیرش ارقام فارسی و جداکننده هزارگان

## پیش‌نیازها
- ویندوز ۱۰ یا ۱۱
- Python 3.9 یا بالاتر (از python.org؛ گزینه Add to PATH را بزنید). Tkinter همراه نصب استاندارد Python است و بسته اضافه‌ای لازم نیست.

## اجرا
```
python shareholders.py
```
یا فایل `run.bat` را دوبار کلیک کنید.

## ساخت فایل exe
```
build.bat
```
خروجی در `dist\Shareholders.exe` ساخته می‌شود و روی ویندوزِ بدون Python هم اجرا می‌شود.

ساخت خودکار با GitHub Actions: workflow در `.github/workflows/build.yml` با ساخت تگ مثل `v1.0.0` یا اجرای دستی، فایل exe را به‌صورت artifact تولید می‌کند.

## نحوه استفاده
1. نام شرکت و ارزش اسمی هر سهم (ریال) را بالای صفحه وارد و «اعمال» را بزنید.
2. مشخصات سهامدار را در فرم پر و «ذخیره» را بزنید.
3. برای ویرایش، ردیف را در جدول انتخاب کنید، فرم را تغییر دهید و «ذخیره» بزنید.
4. «چاپ» گزارش را در مرورگر پیش‌فرض باز می‌کند و پنجره چاپ ویندوز ظاهر می‌شود؛ برای PDF از Save as PDF استفاده کنید.
5. «خروجی Excel (CSV)» فایل CSV با کدگذاری UTF-8 می‌سازد.

## محل ذخیره داده‌ها
`%USERPROFILE%\shareholders_data.json` (فرمت JSON). برای پشتیبان‌گیری یا انتقال به رایانه دیگر همین فایل را کپی کنید.

```json
{
  "company": "نام شرکت",
  "nominal": 1000,
  "people": [
    {"name": "علی رضایی", "nid": "0012345678", "total": 1000,
     "pledged": 200, "start": 1, "end": 1000, "note": ""}
  ]
}
```

```
CHANGELOG.md  LICENSE  .gitignore
```

## تعاریف و فرض‌ها
- «سهام اصلی» همان سهام آزاد، یعنی کل منهای وثیقه، حساب می‌شود.
- سهام وثیقه بخشی از کل سهام هر فرد است.
- درصد مالکیت = کل سهام فرد ÷ مجموع کل سهام همه سهامداران.
- ارزش اسمی = تعداد کل سهام × ارزش اسمی هر سهم.
